# 마케팅 일지와 콘텐츠 운영관리

기존 콘텐츠 Netlify 프로젝트의 Base directory는 `dashboard`입니다. 빌드 명령과 Functions 위치는 `netlify.toml`에 정의되어 있습니다.

## 미리보기

- Netlify Identity를 활성화하고 가입 방식을 초대 전용으로 설정합니다.
- Functions 환경에 `JOURNAL_ADMIN_EMAIL`을 설정합니다. 이 이메일로 로그인한 계정에 작성 권한이 있습니다. 사이트 접속자는 로그인 없이 읽기 화면을 사용합니다. 작성·수정·삭제는 관리자 계정으로 로그인한 경우에만 가능합니다. 사이트 주소를 아는 사람은 누구나 기록을 열람할 수 있습니다.
- 미리보기는 주소별 공유 저장소를 사용하므로 같은 미리보기를 다시 배포해도 기록이 유지됩니다. 운영 저장소와는 분리되어 있습니다. 샘플 기록으로 관리자 저장, 팀원 열람, 팀원 저장 거부, 백업 복원을 확인합니다.

## 운영 전환

- 기존 운영 콘텐츠를 JSON으로 백업합니다.
- Functions 환경에 `JOURNAL_PRODUCTION_ORIGIN`을 기존 운영 주소인 `https://inspiencontent.netlify.app`로 설정합니다. 이 주소에서만 운영 저장소를 사용합니다.
- 운영 공유 저장소가 비어 있으면 기존 `content-dashboard` 저장소에서 콘텐츠·블로그 통계·사업부 설정을 읽습니다. 첫 관리자 저장 시 통합 저장소에 복사되며 원본 저장소는 수정되지 않습니다.
- 관리자 화면의 **백업 복원**으로 기존 일지 JSON을 가져옵니다. 이전 형식의 일지는 이미 저장된 기록과 합칩니다. 백업에는 업무 데이터가 포함될 수 있으므로 저장소에 커밋하지 않습니다.
