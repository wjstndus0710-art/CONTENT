# 멀티채널 콘텐츠 운영 대시보드

「26_멀티채널 콘텐츠 운영관리」 시트를 웹에서 한눈에 보고 관리하기 위한 대시보드입니다. 세 가지 방법으로 쓸 수 있습니다: claude.ai 링크, Netlify 사이트([NETLIFY.md](NETLIFY.md)), `public/index.html` 파일 직접 열기.

처음 데이터는 시트의 「멀티채널 콘텐츠 운영 현황」 탭과 블로그 통계 리포트에서 옮겼습니다.

## 화면 구성
- **대시보드**: 배포 완료 콘텐츠·평균 진행률, 채널 칸 기준 배포 현황, 채널별 완료율, 채널별 상태 누적 막대, 사업부/서비스별 콘텐츠 수, 월별 원문 발행 수, 네이버 노출 현황, 배포가 남은 콘텐츠
- **우측 패널** (대시보드): 다음/최근 원문 발행, 채널 배포 할 일(예약·검수중·작성중·미작성 칸), 사업부별 평균 진행률
- **운영 현황**: 시트와 같은 열 구성의 표. 상태 칩을 누르면 `미작성 → 작성중 → 검수중 → 예약 → 발행완료 → 빈칸` 순서로 바뀝니다. 주제를 누르면 편집합니다.
- **콘텐츠 캘린더**: 원문 발행일 기준, 월요일 시작. 빈 날짜를 더블클릭하면 그 날짜로 추가합니다.
- **키워드 관리**: 메인/서브 키워드, 네이버 노출, 같은 메인 키워드를 쓰는 콘텐츠 ‘중복’ 표시
- **블로그 성과**: 「블로그 통계(26년 N월)」 리포트와 같은 구조로 커넥트·인스피언 네이버 블로그의 월별 조회수·순방문자수·체류시간·포스팅수와 조회수 TOP5를 봅니다.
  - 처음 데이터: 26년 7·8·9월 리포트 탭의 23.05 ~ 26.09 통계
  - 기준 월 선택, 블로그별 카드(전월·전년 동월 대비 증감률, 포스팅당 조회), 두 블로그 비교 추이(12개월/24개월/전체), 월별 증감률 표, TOP5(연속 진입 개월 수 표시)
  - 매달 **블로그 통계 가져오기**로 리포트 엑셀을 그대로 올리면 됩니다. 여러 탭이 있으면 최신 탭 값이 우선이고, 같은 블로그·같은 월은 덮어씁니다.
  - 최신 탭의 값이 다른 블로그의 같은 달 값과 똑같으면(복사 실수로 보임) 이전 탭 값을 쓰고 알려 줍니다. 처음 데이터의 인스피언 26.06·26.07이 이 경우입니다.
  - 체류시간은 시트 값을 단위 변환 없이 그대로 표시합니다.

진행률은 시트 수식과 같습니다: `COUNTIF(네이버:카카오, "발행완료") / 4` (인스타는 진행률에 포함하지 않음).

## 시트에서 가져오기
왼쪽 메뉴 **데이터 관리 → 엑셀/CSV 가져오기**에서 시트 파일(.xlsx)을 그대로 올리거나 CSV를 올립니다.
- 엑셀 파일은 「운영 현황」 탭을 먼저 찾고, 맨 위 제목 줄은 자동으로 건너뜁니다.
- 인식하는 열: 사업부/서비스, 콘텐츠 주제, 메인 키워드, 네이버 노출, 서브 키워드, 원문 채널, 원문 발행일, 네이버, 홈페이지, 티스토리, 카카오, 인스타, 담당자, 비고 (진행률은 자동 계산)
- 엑셀 읽기에는 SheetJS를 CDN에서 불러오므로 인터넷 연결이 필요합니다. 연결이 없으면 CSV로 저장해 가져오세요.

**CSV 내보내기**는 같은 열 순서로 저장하므로 구글 시트에 다시 붙여 넣을 수 있습니다.

## 데이터 저장
- **Netlify 사이트**: 로그인 후 Netlify Blobs에 저장됩니다. 설정 방법은 [NETLIFY.md](NETLIFY.md).
- **claude.ai 링크**: 링크 소유자만 읽고 쓸 수 있는 서버 저장소에 저장됩니다. 왼쪽 위 상태 표시가 `서버에 저장됨`인지 확인하세요.
- **`public/index.html`을 파일로 열 때**: 이 브라우저(localStorage)에만 저장되고 빈 상태로 시작합니다. 엑셀 가져오기나 JSON 백업 불러오기로 데이터를 넣으세요.

세 방법 모두 화면은 브라우저 캐시로 먼저 그린 뒤 서버 데이터로 바뀌며, 수정한 문서만 하나씩 저장합니다. JSON 백업에는 콘텐츠와 블로그 통계가 모두 들어가서 방법 사이를 옮길 때 씁니다.

## 폴더 구조
- `public/` — 화면(`index.html`, `styles.css`, `app.js`)
- `netlify/functions/api.mjs` — Netlify용 저장·로그인 API
- `data/seed.mjs` — Netlify 저장소를 처음 채우는 데이터(함수 안에만 포함)
- `test/` — API 테스트 (`npm test`)
