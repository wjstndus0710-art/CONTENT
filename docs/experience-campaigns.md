## 업체별 주의사항

### ① 다홍 난곡2호점
- 주말(토·일) 체험 불가 → 평일로 잡기
- 방문 전 반드시 전화 예약 후 시간 조율
- 체험 후 1주일 이내 리뷰
- (선택) 네이버 클립: 업체 지도 표시 + 해시태그 5개, **해시태그를 먼저** 쓰고 내용은 짧게

### ② ATLAS BAR
- 방문은 **오후 7:30~8:00** 으로 최대한 맞춰 달라는 요청
- 주말 제한은 적혀 있지 않음 (예약 시 확인)
- (선택) 인스타·페이스북 등 SNS 동시 게시 우대

### ③ 인씨주막
- **금요일 체험 불가**, **20시 이전**에만 체험 가능
- 예약 전 **문자 먼저** 보내기
- 2인 기준 체험권
- ⚠️ 리뷰를 **AI·ChatGPT로 쓰지 말고** 실제 경험을 바탕으로 직접 작성해 달라는 요청

### ④ 화요반점 본점 (가장 촉박)
- **선정 후 1주일 이내 방문**, **방문 후 3일 이내 리뷰**
- 저녁 시간대만 가능
- 예약 대신 예약번호로 `방문 요일·시간 / 방문 인원` 문자 → 방문 시 **초청장 제시**
- 2인 기준. 추가 인원은 추가 메뉴·주류 주문 및 **본인 결제**
- 20~40대만 체험 가능 (50대 이상 불가)
- 리뷰 작성 후 **링크를 예약번호로 꼭 전송** (현장에서 보여줘도 됨)
- (선택) 네이버 클립 작성 시 `#협찬` 해시태그를 **최상단**에, 지도 표시 + 해시태그 5개

## 4곳 공통 블로그 미션
- 사진 **최소 15장** (동영상 포함)
- 본문 **1,000자 이상**
- 본문 하단에 **지도 위치 링크**
- 제목·본문에 **지정 키워드 + 자율 키워드 1개를 3회 이상**
- 제목은 **키워드 + 업체명** 포함, 간결하게
- 미션 미준수 시 수정 요청 가능

## 추천 순서
1. **화요반점** – 방문 기한(선정 후 7일)과 리뷰 기한(방문 후 3일)이 가장 짧음
2. **다홍** – 평일만 가능, 방문 후 7일 내 리뷰
3. **인씨주막 / ATLAS BAR** – 등록기간 안에서 일정 조율
   - 같은 날 두 곳을 가려면: 인씨주막(20시 전) 먼저 → ATLAS BAR(19:30~20:00)는 시간이 겹치므로 **다른 날로 나누는 게 안전**
   - 인씨주막은 금요일 제외
