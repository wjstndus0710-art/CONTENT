# 멀티채널 콘텐츠 운영 대시보드

「26_멀티채널 콘텐츠 운영관리」 시트를 웹에서 한눈에 보고 관리하기 위한 대시보드입니다. 빌드나 설치 없이 `index.html`을 브라우저로 열면 바로 동작합니다.

처음 열면 시트의 「멀티채널 콘텐츠 운영 현황」 탭 데이터 18건(`seed.js`)이 들어 있습니다.

## 화면 구성
- **대시보드**: 배포 완료 콘텐츠·평균 진행률, 채널 칸 기준 배포 현황, 채널별 완료율, 채널별 상태 누적 막대, 사업부/서비스별 콘텐츠 수, 월별 원문 발행 수, 네이버 노출 현황, 배포가 남은 콘텐츠
- **우측 패널** (대시보드): 다음/최근 원문 발행, 채널 배포 할 일(예약·검수중·작성중·미작성 칸), 사업부별 평균 진행률
- **운영 현황**: 시트와 같은 열 구성의 표. 상태 칩을 누르면 `미작성 → 작성중 → 검수중 → 예약 → 발행완료 → 빈칸` 순서로 바뀝니다. 주제를 누르면 편집합니다.
- **콘텐츠 캘린더**: 원문 발행일 기준, 월요일 시작. 빈 날짜를 더블클릭하면 그 날짜로 추가합니다.
- **키워드 관리**: 메인/서브 키워드, 네이버 노출, 같은 메인 키워드를 쓰는 콘텐츠 ‘중복’ 표시

진행률은 시트 수식과 같습니다: `COUNTIF(네이버:카카오, "발행완료") / 4` (인스타는 진행률에 포함하지 않음).

## 시트에서 가져오기
왼쪽 메뉴 **데이터 관리 → 엑셀/CSV 가져오기**에서 시트 파일(.xlsx)을 그대로 올리거나 CSV를 올립니다.
- 엑셀 파일은 「운영 현황」 탭을 먼저 찾고, 맨 위 제목 줄은 자동으로 건너뜁니다.
- 인식하는 열: 사업부/서비스, 콘텐츠 주제, 메인 키워드, 네이버 노출, 서브 키워드, 원문 채널, 원문 발행일, 네이버, 홈페이지, 티스토리, 카카오, 인스타, 담당자, 비고 (진행률은 자동 계산)
- 엑셀 읽기에는 SheetJS를 CDN에서 불러오므로 인터넷 연결이 필요합니다. 연결이 없으면 CSV로 저장해 가져오세요.

**CSV 내보내기**는 같은 열 순서로 저장하므로 구글 시트에 다시 붙여 넣을 수 있습니다.

## 데이터 저장
데이터는 사용하는 브라우저(localStorage)에 저장됩니다. 다른 기기나 팀원과 공유하려면 **백업 저장(JSON)** 또는 CSV를 주고받으세요. 브라우저 데이터를 지우면 함께 삭제되니 주기적으로 백업해 두세요. **처음 데이터로 되돌리기**는 `seed.js`의 시트 데이터로 초기화합니다.

## 배포
정적 파일 4개(`index.html`, `styles.css`, `seed.js`, `app.js`)뿐이라 GitHub Pages, Netlify 등에 그대로 올리면 됩니다.
