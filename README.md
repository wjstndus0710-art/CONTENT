# 콘텐츠 대시보드

시트 대신 한 화면에서 콘텐츠 마케팅을 관리하는 웹 대시보드입니다. 빌드나 설치 없이 `index.html`을 브라우저로 열면 바로 동작합니다.

## 화면 구성
- **대시보드**: 총 조회수·콘텐츠 현황 카드, 성과 요약(참여율·클릭·전환·전환율·마감 지남), 채널별 조회수, 제작 파이프라인, 월별 발행 수/조회수, 성과 상위 콘텐츠
- **우측 패널**: 최근 30일 베스트 콘텐츠, 14일 내 마감·발행 일정, 캠페인별 진행률
- **콘텐츠 목록**: 정렬 가능한 표, 행 클릭으로 편집
- **칸반 보드**: 아이디어 → 기획 → 제작중 → 검수 → 발행예정 → 발행완료, 드래그로 상태 변경
- **캘린더**: 발행일/마감일 기준 월간 일정, 빈 날짜 더블클릭으로 추가

상단 필터(검색·채널·상태·담당자·캠페인·기간)는 모든 화면에 함께 적용됩니다.
단축키: `N` 새 콘텐츠, `/` 검색.

## 시트에서 옮겨오기
1. 구글 시트/엑셀에서 **CSV로 다운로드**합니다.
2. 왼쪽 메뉴 **데이터 관리 → CSV 가져오기**를 누릅니다.

인식하는 열 이름(한글/영문): 제목, 채널, 형식, 상태, 담당자, 캠페인, 태그, 마감일, 발행일, URL, 조회수, 좋아요, 댓글, 공유, 클릭, 전환, 메모. `제목` 열만 필수이며 날짜는 `2026-10-12`, `2026.10.12`, `2026/10/12` 형식을 지원합니다. **CSV 내보내기**로 받은 파일을 템플릿으로 써도 됩니다.

참여율 = (좋아요 + 댓글 + 공유) ÷ 조회수

## 데이터 저장
데이터는 사용하는 브라우저(localStorage)에 저장됩니다. 다른 기기나 팀원과 공유하려면 **백업 저장(JSON)** 파일을 주고받거나 CSV를 사용하세요. 브라우저 데이터를 지우면 함께 삭제되니 주기적으로 백업해 두세요.

## 배포
정적 파일 3개(`index.html`, `styles.css`, `app.js`)뿐이라 GitHub Pages, Netlify 등에 그대로 올리면 됩니다.
